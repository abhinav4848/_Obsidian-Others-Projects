# 2023-03-31 Patreon letter - Memory systems and problem-solving practice
_Summary of the source letter._

Remembering definitions and equations does not guarantee the ability to solve unfamiliar problems. Following a physics learner, Matuschak examines how practice must engage the processes needed in real use, help learners develop adaptable problem-solving patterns, and expose unnoticed comprehension gaps. The letter asks how memory practice, varied exercises, and conversation can work together to produce usable understanding rather than accurate repetition alone.
