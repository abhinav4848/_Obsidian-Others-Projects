# 2021-02-02 Patreon letter - In search of better questions
_Summary of the source letter._

Accumulating memory data is useful only when research questions can produce meaningful new understanding. Matuschak challenges vague evaluations of whether a system works and narrow studies concerned only with memorization. He seeks questions about how reading tools change learning, feeling, and action. The letter treats choosing the right questions and collecting the corresponding evidence as prerequisites for inventing more powerful learning environments.
