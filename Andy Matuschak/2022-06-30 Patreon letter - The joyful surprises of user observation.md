# 2022-06-30 Patreon letter - The joyful surprises of user observation
_Summary of the source letter._

Live observation shows that a prototype can change readers' behavior in ways its designer did not anticipate. Matuschak argues for lightweight experiments and an open-ended stance toward discovering new needs. Readers sometimes use memory prompts as summaries or navigation aids, and many dislike sustained reading on a computer. These observations reshape the design problem beyond checking whether the original feature works as intended.
