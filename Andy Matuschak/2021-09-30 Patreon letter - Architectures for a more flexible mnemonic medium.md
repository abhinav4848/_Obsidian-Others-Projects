# 2021-09-30 Patreon letter - Architectures for a more flexible mnemonic medium
_Summary of the source letter._

The proposed mnemonic-medium architecture supports different reading situations without forcing everyone through the same sequence. Readers should be able to select, edit, and create prompts using representations shared with the author's prompts. Matuschak explores compact lists, contextual interactions, and optional review at section breaks. The design aims to preserve guided learning where useful while accommodating selective reading, personal connections, and changes made during later review.
