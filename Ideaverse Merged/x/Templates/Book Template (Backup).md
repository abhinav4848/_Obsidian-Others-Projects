# Book Template (Backup)

```

  - "[[{{author}}]]"

published: {{publishDate}}
created: {{DATE:YYYY-MM-DD}}

  - "#source/book"

bookCategory: {{category}}
bookGroup: 
pages: {{totalPage}}
image: {{coverUrl}}
year: 
yearXP: 
yearXPL:

rating:
---

```
